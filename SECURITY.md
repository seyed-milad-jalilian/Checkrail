# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

Checkrail is pre-1.0, experimental software. Only the latest `0.1.x` line on `main` receives security fixes.

## Reporting a Vulnerability

Security is paramount in AI agent governance. If you discover a security vulnerability or a guardrail bypass mechanism in Checkrail:

1. **Do not create a public issue or pull request** that exposes the details.
2. Prefer GitHub's **private vulnerability reporting**: open the repository's *Security* tab and choose *Report a vulnerability*. (If the maintainer has not enabled private reporting, the form will not appear — use the fallback below.)
3. Fallback: contact the maintainer, **@seyed-milad-jalilian**, directly through GitHub (profile contact options).

Please include details of the vulnerability, reproduction steps, and the potential impact. We will acknowledge receipt within 48 hours and coordinate a timely fix and responsible disclosure.

### For the maintainer

Keep GitHub private vulnerability reporting enabled under *Settings → Code security and analysis* so channel 2 above is always available. Do not commit secrets, tokens, or keys to this repository in any branch.
